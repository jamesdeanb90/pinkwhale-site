# pinkwhale-site

Single-page site for Chill Whale ($PINK) and the Pink Whale Pod community (target domain: pinkwhalepod.app).
Static HTML + CSS, no JavaScript, no build step, no trackers, self-hosted fonts.

- `index.html`, `styles.css` — the page
- `img/` — canonical pink whale SVG, OG image (no QR), app screenshots captured read-only from the live room
- `fonts/` — Poppins 800 + Nunito subsets (OFL)
- `review/` — headless screenshots at 375px and 1280px

**Status: local build only. Not deployed. GitHub Pages is not enabled. Do not deploy without James's OK.**

Preview: open `index.html` in a browser, or `python3 -m http.server` in this folder.
Build notes: `/workspace/chill-whale-hq/pinkwhale-site-build-notes.md` (on the shared box).
